# portifolio-ju

Portfólio web de **Juliana** — Publicidade e Propaganda, UNIFRAN Franca.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Conteúdo

Textos, contatos e trabalhos ficam em `src/lib/site.ts`. Contatos vazios (e-mail/Instagram) não são exibidos.

## Deploy (Vercel)

1. Conecte o repositório na [Vercel](https://vercel.com)
2. Deploy automático a cada push na branch principal
